# ppl-language
PPL (Portuguese Programing Language) is a new programming language created to be simple like lua.
the key difference from the others is that the syntax is in Portuguese Brazilian (you know what that means, that is made by a Brazilian!)
and the project was (a little) vibe coded

# Installation
To install PPL and ppl-man, run this:
```bash
curl -fsSL https://raw.githubusercontent.com/bernardo58247/ppl-programming-language/refs/heads/main/install.sh | bash
```

## 💡 Philosophy

> *"If you are going to create something, make it unique, not a copy."*  
> — **Bernardo**

**PPL** and **ppl-man** were born from this vision. The goal is to deliver an original, minimalist, portuguese-based, and decentralized experience without trying to imitate the overhead or bureaucracy of traditional programming languages.
