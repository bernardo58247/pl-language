# ppl-language
O PPL (Portuguese Programing Language) é uma nova linguagem de programação feita para ser fácil igual o lua.
a maior diferença é que a sintaxe é em Português Brasil (voce sabe o que significa, que foi feito por um Brasileiro!)
e o projeto foi (um pouquinho) guiada por IA

# Installation
Para instalar rode isso:
```bash
curl -fsSL https://raw.githubusercontent.com/bernardo58247/ppl-programming-language/refs/heads/main/install.sh | bash
```
