# PPL Language
## Uma linguagem de programação moderna

"Se você for criar uma coisa, faça ela ser única, não uma cópia."

### Compatibilidade & Leveza
Execute scripts `.ppl` e `.ppls` diretamente no Termux ou Linux. Conta com gerenciamento descentralizado de bibliotecas via `ppl-man` e suporte nativo em português.

### ⚡ Instalação Rápida
Rode o comando abaixo no seu terminal:

```bash
curl -fsSL [https://raw.githubusercontent.com/bernardo58247/ppl-programming-language/main/install.sh](https://raw.githubusercontent.com/bernardo58247/ppl-programming-language/main/install.sh) | bash
